# empty-solid-app
Empty Solid app

This mainly shows how to create a Solid app using [Inrupt Solid Client](https://github.com/inrupt/solid-client-authn-js). The source code
can be seen with the `View Source` feature of your browser, or on [https://github.com/michielbdejong/empty-solid-app](https://github.com/michielbdejong/empty-solid-app).

It is also publicly hosted on [https://empty-solid-app.pondersource.com](https://empty-solid-app.pondersource.com).
